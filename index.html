FCosta Gestor

Frente de caixa, estoque e financeiro para o mercado — funciona offline, no seu computador.

1. Baixar e instalar

⬇️ Baixar instalador (Windows)

  1. Baixe o arquivo FCostaGestor-Instalador.exe clicando no botão acima.
  2. Dê dois cliques para instalar e siga as telas (Avançar → Instalar → Concluir).
  3. Abra pelo atalho FCosta Gestor na área de trabalho.

Se o Windows mostrar "O Windows protegeu seu computador" (o instalador não tem assinatura digital paga), clique em Mais informações → Executar assim mesmo.

⚠️ Use sempre o mesmo navegador

Os dados ficam guardados no navegador deste computador. Abra o sistema sempre pelo atalho, no mesmo navegador e perfil de sempre (de preferência Chrome ou Edge). Em outro navegador, em modo anônimo ou depois de limpar os dados de navegação, o sistema abre vazio.

Não use este sistema abrindo por um endereço da internet: lá os dados ficariam separados dos do computador. Instale e use pelo atalho.

2. Proteja seus dados (backup)

  • Em Cadastros → Impressora & Backup → Backup automático, escolha uma pasta (de preferência num pen-drive ou numa pasta nova como Backup FCosta). O sistema grava lá um arquivo por dia.
  • O sistema também guarda cópias internas a cada 3 minutos e, se abrir vazio ou incompleto, oferece recuperar.
  • Baixe um backup completo pelo menos uma vez por semana e guarde fora do computador.
  • Antes de confiar num backup, confira se ele abre e tem tamanho normal. Arquivo zerado não restaura nada.

3. Atualizações

Com o computador conectado à internet, o sistema verifica sozinho se há versão nova e mostra um aviso 🔄 Atualização no topo. Basta clicar, fazer o backup, baixar e executar o novo instalador. Seus dados continuam no navegador.

Também dá para verificar à mão em Cadastros → Impressora & Backup → Atualização do sistema. Versão atual: 2.4.0.

4. Conferir se o instalador veio inteiro

No Windows, abra o Prompt de Comando na pasta do arquivo baixado e rode:

certutil -hashfile FCostaGestor-Instalador.exe SHA256

O resultado deve ser exatamente:

0783a53b8f2e1e5c43dfe57b6f0824b198ea3e941957b9026a9f1e8ba071168f

Se for diferente, o download veio incompleto ou foi alterado: apague e baixe de novo.

Sem instalar

Também dá para usar o arquivo fcosta-gestor.html sozinho: baixe, salve numa pasta fixa e abra sempre por ele no mesmo navegador.
